# Resources and field notebooks

Tools & resources links to the existing estimating portal and its cabinet layout screen. These are launch links with the existing portal authentication and saved projects, not a new single sign-on or automatic estimate/layout transfer into CRM. Portal IDs must never be inferred from CRM/Job Tracker IDs.

The team library supports admin-uploaded files and folders with relative names preserved. Staff can search and download; every download checks the authenticated role. Files are stored in PostgreSQL, not ephemeral app storage. Limits: 25 MB/file and 500 MB total. Supported documents, images, text, and ZIP archives download as attachments; uploaded scripts are never executed. Folder uploads are sequential and report individual failures. ZIP files are stored as archives, not automatically unpacked. No removal action is exposed in this release.

My notes & drawings holds each author's notebooks. Creating one inside an opportunity or owner Job Tracker detail links it to that exact record; standalone drafts can be explicitly assigned later. Linked sales notebooks also appear on the linked Job Tracker record. Rep access follows their lead/job ownership; personal unassigned notes stay with the author and admins. Operations sees handed-over opportunity notes; designers need an assigned work request. Only the author or admin edits an existing notebook. Other team members can add their own notebook where permitted.

Notes store editable stroke coordinates and typed measurements. Autosave runs every 1.5 seconds after edits, with a per-account IndexedDB device draft written on each completed stroke/change. Server revision checks stop competing-device overwrites; identical retries are idempotent. Unsynced device drafts are listed on reopen and retry when connected. Local drafts are not a substitute for a hosted save: browser storage can be cleared, evicted, or unavailable. The app shell itself is not offline-cached; open the page before losing connectivity. Never claim loss-proof storage. Pencil/mouse mode ignores touch strokes; finger drawing can be enabled explicitly. PNG and JSON backup export are available. The author should confirm Saved to workspace before closing or clearing browser data. No destructive notebook delete is exposed.

Migration 0015 is additive. Limits are two megabytes of notebook content, 2,000 strokes/page, and 20,000 points/stroke. Large drawings should use a new notebook/page.

## Embedded customer tools

Sales and Operations customer panels now open the existing designer and estimator inside the workspace. Both use one deterministic portal job/customer/tenant per opportunity; repeated launches do not create a second estimate or a financial Job Tracker job. Existing unlinked portal projects are unchanged; historical associations require explicit review rather than name matching.

The workspace issues a random eight-hour capability, stores only its SHA-256 digest, and rechecks the user's active account, credential version, and customer assignment on every portal API call. Closing the panel revokes that capability; logout revokes all grants for that user. No portal administrator credential is shared. The portal limits embedded access to one customer and retains rep markup validation. No environment secret setup is required.

The token enters the tool through a URL fragment, is removed immediately, stays in memory, and is sent only to same-origin portal API routes. The portal verifies it server-to-server with the fixed workspace origin. A narrowly scoped HttpOnly cookie allows designer assets to load; customer API calls still require the in-memory token. Embedded draft storage is scoped to the workspace user and job. Only the workspace origin is added to the designer's frame-ancestor allowance; the original standalone designer protection is unchanged.

Users must use the existing Save / Save to job controls before closing. Closing warns about unsaved work. This is not an automatic import of historical portal projects, an offline app, or bidirectional synchronization of later contact edits. Customer details populate the linked estimate on first open and subsequent launches preserve saved estimate data.
